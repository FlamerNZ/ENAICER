Blend A/B: your drills

Each pair has three model versions (A, B, C, in a fixed random order) and your own take from the drill. All are at the same loudness and start at the same point in the music, so switching keeps your place: pick a version while it plays to hear the same moment in another. Pick the best, thumb each one, and add a note if something stands out. Everything saves as you click. "Reveal" shows which version is which.
